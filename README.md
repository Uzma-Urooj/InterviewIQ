# InterviewIQ — AI Interview Agent

InterviewIQ is an AI-powered interview platform designed to help candidates practice and improve their interview skills through realistic, interactive interview sessions.

The platform provides an engaging interview experience with modern UI animations, authentication, payment integration, and a full-stack architecture.

## Features

- AI-powered interview agent
- Interactive interview practice
- Google Authentication using Firebase
- Razorpay payment integration
- Modern and responsive UI
- Smooth animations with Framer Motion
- MongoDB database
- REST API with Node.js & Express.js
- Deployed on Render

## Tech Stack

### Frontend
- React.js
- Framer Motion

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- Firebase Google Authentication

### Payments
- Razorpay

### Deployment
- Render
